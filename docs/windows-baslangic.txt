YÖRÜNGE STUDIO v0.5 — WINDOWS

1. ZIP paketini tamamen bir klasöre çıkar.
2. Yorunge.exe dosyasına çift tıkla. Tüm dosyaları aynı klasörde tut.
3. Malzemeler > Özel yapı düzenle: atom ekle, Å koordinatlarını değiştir,
   örgü üret veya XYZ dosyası aç. Üstteki diğer çalışma alanlarını seç.
4. Deneylerini Kaydet ile JSON, hesap sonuçlarını CSV olarak sakla.

Uygulama kendi penceresinde açılır. Kapatıldığında kendi hesap motoru da
kapanır. Rust/Node kurulumu gerekmez. Windows x64, .NET Framework 4.8+
ve Microsoft WebView2 Runtime gerekir. Eksik runtime için resmi adres
uygulamada gösterilir. Masaüstü kısayolu Yorunge.exe dosyasını hedefler.

Yerel deney verileri/günlükler: %LOCALAPPDATA%\Yorunge\Studio
Kullanılan yerel port: 17971. Meşgul porttaki başka servise bağlanılmaz.
Önceki tarayıcı oturumunun kayıtları otomatik taşınmaz; eski alandan
JSON kaydedip masaüstü uygulamasında açabilirsin.

Alanlar: Özel atom yapıları, 118 element, molekül grafı, hücre taşınımı,
enzim kinetiği, katı cisim mekaniği, DC direnç ağı, ısıtma/soğuma.
Bu modellerin kapsamı ayrıdır. Serbest atom dizilimi gerçek maddenin
kararlılığını veya tepkimelerini öngörmez. Model denklemleri, kullanım ve
sınırlar README.md ile docs/ klasöründedir. Üçüncü taraf bildirimleri de
pakette bulunur. Farklı Windows kurulumlarının tümü test edilmedi.
